### PDF下载失败及处理

- 上述WHO出版物页给出的 IRIS PDF 直链已核验书目、摘要、页数和许可；本机对 `iris.who.int` 的连接超时，二进制未下载、未入库。不得将信息页提取结果称为PDF全文。
- 首轮本地PDF解析还暴露 `Buffer` 与 `unpdf` 输入兼容问题，已改为传入独立 `Uint8Array`；但因网络连接失败，尚未用这些WHO文件完成端到端PDF验证。
- Git忽略目录中只保存成功采集的原始响应；未产生WHO PDF原件。

### 审核发现

- 同一篇中国政府网政策解读因标题标点差异形成两个知识源记录，SHA256相同。清单标题已统一，数据库旧记录暂保留，后续可做安全的逻辑合并。
- 当前9个版本记录对应8种内容；Markdown导出6份，其中有一份重复政策新闻；三份WHO信息页按许可设置未导出。

### 初步内容核验

- 国办发〔2019〕15号页面包含发文信息、正文和部门职责分工附件，正文长度与官方页面相符。
- 国卫人口发〔2019〕58号公报转载包含《托育机构设置标准（试行）》《托育机构管理规范（试行）》及备案附件，需再与国家卫健委原始发布页逐项比对版本完整性。
- 采集阶段只核验来源、文件身份和文本提取，不据此确认法律效力，也未把条款转化为回答或建议。
- Markdown 中保留页级锚点；当前 HTML 页面作为单页文本，尚没有 PDF 页码。问答引用应优先使用文号、条款和官方链接，不虚构 PDF 页码。
- 国标、行业标准和第三方教材没有在本批次下载全文；待版权/授权登记完成后再决定是否采集全文。
