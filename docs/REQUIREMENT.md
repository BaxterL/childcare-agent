## 原文

**托育知识库垂直大模型（知识问答型 · 托育RAG）**

截止时间：11-08
负责人：wangzongjin
创建人：zhangjun@gmail.com

任务描述

【定位】知识问答型 —— 垂域知识库 + RAG 检索增强。

【目标】面向托育（婴幼儿照护）领域建设结构化知识库，配合垂直大模型实现专业问答，答案可溯源。

【主要工作】① 语料建设：托育政策法规、行业标准、照护与保育实操资料的采集、清洗、去重、结构化；② 知识库：文本分块、向量化入库、元数据标注（来源/时间/主题），支持增量更新；③ 检索增强：混合召回 + 重排，多轮追问，答案附原文出处；④ 垂域调优：领域提示词或微调，抑制幻觉、超范围拒答；⑤ 应用层：问答入口（网页/接口），可限定知识范围。

【交付物】可运行的问答应用 + 知识库 + 评测问题集与准确率/引用命中报告 + 部署使用说明。

【验收】评测集上回答准确且引用可溯源；新增资料可增量入库并生效。

## 范围确认（2026-10-10 需求方确认）

- 适用地区：**全国**
- 适用年龄：**婴幼儿标准年龄范围（0~3 岁）**，对应代码枚举 `age_range = 0-3_years`
